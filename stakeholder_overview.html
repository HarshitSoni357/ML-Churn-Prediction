What this repo delivers

  • Time-aware churn prediction using customer lifecycle signals
  • Multiple model evaluation to reduce risk of overfitting
  • MLflow-style model comparison and governance mindset
  • FastAPI service for serving predictions in production-like environments
  • Monitoring, drift review, and deployment artifact validation

Why this matters to stakeholders
This project demonstrates a disciplined, production-oriented ML workflow: build data correctly, evaluate models over time, validate artifacts before serving, and monitor for drift or performance issues. The emphasis is on process quality, operational safety, and reproducibility—not on claiming real-world business lift from synthetic data.

Core technical components

  • Python-based ML pipeline
  • FastAPI prediction service
  • Docker and Docker Compose deployment
  • Prometheus + Grafana + Alertmanager
  • Model packaging and metadata validation

Key caveat

  • Dataset is synthetic, not production customer data
  • It is a portfolio and demo project
  • Performance metrics should be interpreted as engineering evidence, not business truth
